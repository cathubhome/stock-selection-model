# A股选股研究模型

这是一个仅用于研究和回测的本地选股研究工作台：

```text
AKShare公开数据 → 技术/量价/K线因子 → LightGBM滚动训练 → 舆情关键词评分 → 综合评分 → 无未来数据泄漏回测
```

当前版本不包含下单、券商连接或实盘交易功能。

## 环境

```powershell
conda create -n stock-model python=3.10 -y
conda activate stock-model
pip install -r requirements.txt
```

## 下载研究数据

先使用少量股票验证流程：

```powershell
python download_data.py --symbols 000001,600000,600519 --start 20180101 --end 20260808
```

按当前市场成交额下载前100只股票：

```powershell
python download_data.py --top-n 100 --start 20180101 --end 20260808
```

`--top-n`使用当前股票池，仅适合流程验证；严肃回测应提供每个历史日期的股票池，避免幸存者偏差。

## 训练并输出候选股票

```powershell
python run_model.py --top-k 20 --horizon 20
```

## 本地Web界面

双击 `start_web.bat`，或执行：

```powershell
python -m streamlit run app.py
```

浏览器会打开 `http://127.0.0.1:8501`。界面仅监听本机地址，不对公网开放。

股票检索支持股票代码、中文名称和拼音首字母，例如 `300476`、`胜宏科技` 或 `SHKJ`。

结果保存在 `output/`，包括：

- `latest_picks.csv`：最新候选股票及综合评分、五项分项评分
- `latest_scores.csv`：最新交易日全部本地股票的评分，用于行情看板
- `feature_importance.csv`：模型因子重要性
- `validation_metrics.json`：样本外验证指标
- `backtest_periods.csv`：每个滚动调仓期的组合、基准和持仓记录
- `backtest_metrics.json`：累计收益、年化收益、最大回撤、夏普、胜率等

## Web 研究流程

页面按四步组织：

1. **数据准备**：按股票代码、名称或拼音首字母检索，下载日线行情。
2. **本地股票**：侧边栏数量按钮可直接进入本地股票页；下拉查看股票，展示最新价、涨幅、换手率、量比和模型分数；卡片支持拖拽自定义顺序，并提供数据完整性诊断。
3. **综合评分**：模型35%、技术面25%、量价20%、K线10%、舆情10%，权重可调并自动归一化。
4. **历史回测**：每个调仓日只用此前数据训练模型；可上传 `symbol,date,score` 格式的历史舆情评分 CSV，并扣除可配置的换仓成本。
5. **当前候选**：查看综合评分和分项解释，避免只看一个不可解释的模型分数。

舆情默认尝试读取公开新闻接口并用可审计关键词词典给出0—100分；接口不可用、没有新闻或没有历史舆情文件时明确按中性50分处理，不伪造覆盖率。

## 研究注意事项

- 财务数据必须按公告日对齐，不能使用未来信息。
- 回测必须加入佣金、印花税、滑点和涨跌停限制。
- 当前回测已提供换仓成本近似项；涨跌停、停牌、流动性冲击和复权口径仍应在正式研究前继续补齐。
- AKShare是开源数据接口，接口和上游数据可能变化；重要数据应和交易所或上市公司公告抽样校验。
- 历史行情下载默认尝试东方财富接口，连接失败时自动回退到腾讯历史行情接口，并在下载结果中标记实际来源。
- 模型输出只是研究结果，不是投资建议。
