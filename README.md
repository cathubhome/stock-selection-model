# A股选股研究模型

这是一个仅用于研究和回测的本地选股研究工作台：

```text
AKShare公开数据 → 技术/量价/K线因子 → LightGBM滚动训练 → 舆情关键词评分 → 综合评分 → 无未来数据泄漏回测
```

当前版本不包含下单、券商连接或实盘交易功能。

## 环境

```powershell
conda create -n stock-model python=3.10 -y
conda activate stock-model
pip install -r requirements.txt
```

## 下载研究数据

先使用少量股票验证流程：

```powershell
python download_data.py --symbols 000001,600000,600519 --start 20180101 --end 20260808
```

按当前市场成交额下载前100只股票：

```powershell
python download_data.py --top-n 100 --start 20180101 --end 20260808
```

`--top-n`使用当前股票池，仅适合流程验证；严肃回测应提供每个历史日期的股票池，避免幸存者偏差。

## 训练并输出候选股票

```powershell
python run_model.py --top-k 20 --horizon 20
```

## 本地Web界面

双击 `start_web.bat`，或执行：

```powershell
python -m streamlit run app.py
```

浏览器会打开 `http://127.0.0.1:8501`。界面仅监听本机地址，不对公网开放。

股票检索支持股票代码、中文名称和拼音首字母，例如 `300476`、`胜宏科技` 或 `SHKJ`。

结果保存在 `output/`，包括：

- `latest_picks.csv`：最新候选股票及综合评分、五项分项评分
- `latest_scores.csv`：最新交易日全部本地股票的评分，用于行情看板
- `feature_importance.csv`：模型因子重要性
- `validation_metrics.json`：样本外验证指标
- `backtest_periods.csv`：每个滚动调仓期的组合、基准和持仓记录
- `backtest_metrics.json`：累计收益、年化收益、最大回撤、夏普、胜率等

## Web 研究流程

页面按五个视图组织，侧边栏切换，全局显示本地数据资产状态：

1. **研究看板**（默认页）：三步研究引导（准备数据 -> 综合评分 -> 历史回测）带完成状态；速览最新候选与回测净值曲线。
2. **股票池与数据**：按代码、名称或拼音首字母检索并加入股票池；下载为真实逐只进度并报告成功/失败清单，失败可单独重试；股票池支持表格排序、弹层一步移除、CSV/Excel 导入导出；内置数据质量诊断。
3. **综合评分**：参数与结果同页——运行后直接展示候选列表、个股正反证据、五维贡献、模型验证指标与因子重要性；支持导出 CSV 与 PDF 报告。候选不会反向改变研究股票池。
4. **历史回测**：滚动训练回测，按总览、有效性、收益风险、执行、暴露和明细组织结果；支持外部基准、买卖成本、滑点、容量、涨跌停、停牌和行业约束。历史舆情不足时会排除舆情维度，不伪装成已验证。
5. **研究记录**：按运行编号追溯数据、参数、验证状态和候选变化；新运行会在 `output/runs/<run_id>/` 保存完整结果文件。

舆情默认尝试读取公开新闻接口并用可审计关键词词典给出0—100分；接口不可用、没有新闻或没有历史舆情文件时明确按中性50分处理，不伪造覆盖率。词典为分级强度（强2/中1/弱0.5），支持否定词反转（如"澄清减持传闻"不记负面）、近因时间衰减（3天内1.0、7天内0.5、30天内0.2）与同事件标题去重。综合评分页可叠加市场情绪面（上涨家数占比、量能、涨停占比合成，仅判断环境强弱，不改变当日排序），每次评分的个股快照与市场情绪自动存档到 data/archive/，用于日后回测验证舆情与情绪权重。

## 研究注意事项

- 财务数据必须按公告日对齐，不能使用未来信息。
- 回测必须加入佣金、印花税、滑点和涨跌停限制。
- 当前回测已模拟买卖成本、滑点、涨跌停、停牌、流动性容量和行业集中约束；复权口径、历史成分范围与历史元数据仍需持续核验。
- AKShare是开源数据接口，接口和上游数据可能变化；重要数据应和交易所或上市公司公告抽样校验。
- 历史行情下载默认尝试东方财富接口，连接失败时自动回退到腾讯历史行情接口，并在下载结果中标记实际来源。
- 模型输出只是研究结果，不是投资建议。
